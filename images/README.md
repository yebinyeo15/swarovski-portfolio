# Swarovski Figma assets

These files were extracted from the final Figma landing-page frame through the Figma MCP asset endpoint.

- Original raster dimensions and PNG encoding are preserved.
- SVG files are stored as returned by Figma.
- `con1` contains no image asset.
- `con6` contains only navigation SVGs.
- Valky font files are intentionally not included because font licensing and redistribution rights are not established.
